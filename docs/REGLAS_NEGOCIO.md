# Reglas de negocio

| Código | Regla | Severidad |
|---|---|---|
| PROG-01 | Un docente no puede tener clases que se solapen. | Bloqueante |
| PROG-02 | Un grupo no puede tener clases que se solapen. | Bloqueante |
| PROG-03 | Una sesión ejecutada no se programa otra vez sin tipo, motivo y aprobación. | Bloqueante |
| PROG-04 | Igual grupo, módulo y tema dentro del periodo configurable genera advertencia. | Advertencia |
| PROG-05 | Todo cambio sensible exige motivo y auditoría. | Bloqueante |
| ID-01 | Documento y correo de estudiante son únicos por organización entre registros activos. | Bloqueante |
| RBAC-01 | La autorización depende de permisos, no del nombre del rol. | Bloqueante |
| AUD-01 | La auditoría es inmutable desde la interfaz convencional. | Bloqueante |
| DOC-01 | Una carga crea versión; nunca sobrescribe la anterior. | Bloqueante |
| ABN-01 | Abandono exige motivo, fecha, responsable, evidencia y última recuperación. | Bloqueante |

Las excepciones de repetición son refuerzo aprobado, recuperación, reposición o sesión extraordinaria.
