# Roadmap

1. Fundaciones: documentación, infraestructura, identidad, catálogos, programación, auditoría y dashboard.
2. Operación: asistencia, riesgo, retención, tickets, SLA y notificaciones.
3. Contenido: documentos, evaluaciones, certificados y exportaciones.
4. Escala: observabilidad, rendimiento, recuperación y adaptación multiunidad.
5. Inteligencia: proveedores reales y casos asistivos con revisión humana.
